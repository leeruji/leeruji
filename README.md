### 소개

[Digginn](https://github.com/Digginn)에서 프로덕트 디자인을 맡고 있습니다.
화면을 그리는 데서 멈추지 않고 AI(Claude Code)와 함께 실제로 돌아가는 앱을 직접 고쳐 봅니다.
개발자는 아니라서 코드를 처음부터 쓰기보다는, 무엇을 왜 바꿀지 정하고 결과를 눈으로 확인하는 일을 합니다.

### 일하는 방식

- 불편한 점을 찾으면 디자이너 눈으로 문제를 정리하고 Claude Code에 바꿀 내용을 설명합니다.
- 바뀐 화면을 직접 켜 보고 간격·글자 위계·색 대비가 의도대로인지 확인합니다.
- 간격은 4px 단위, 색 대비는 WCAG AAA(글자 7:1)를 목표로 잡습니다. 다크 모드도 같이 봅니다.
- 테스트가 통과한 변경만 저장하고 무엇을 왜 바꿨는지 기록으로 남깁니다.

여러 쇼핑몰에 흩어진 관심 상품을 한곳에 모아 보는 아카이빙 앱입니다. [Digginn](https://github.com/Digginn) 팀에서 프로덕트 디자인을 맡고 있고 iOS 앱 출시를 준비 중입니다.
