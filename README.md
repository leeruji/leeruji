### 소개

[Digginn](https://github.com/Digginn)에서 프로덕트 디자인을 맡고 있습니다.
화면을 그리는 데서 멈추지 않고 AI(Claude Code)와 함께 실제로 돌아가는 앱을 직접 고쳐 봅니다.
코드를 처음부터 쓰기보다는, 무엇을 왜 바꿀지 정하고 결과를 눈으로 확인하는 일을 합니다.

### 일하는 방식

- 기능명세서 반영, 정책과 화면 대조, 컴포넌트 설명 작성처럼 팀에서 반복되는 일은 규칙을 문서로 정리해 AI가 매번 같은 방식으로 처리하게 합니다.
- AI에게는 정리와 대조를 맡기고 해석이 필요한 결정과 팀에 공개되는 글은 사람이 확인한 뒤 내보냅니다.
- 화면은 4px 간격 단위와 WCAG AAA 색 대비(글자 7:1)를 기준으로 밝은 테마와 어두운 테마를 함께 봅니다.

### 대표 작업

**[Diggin](https://diggin-landing.vercel.app)**
여러 쇼핑몰에 흩어진 관심 상품을 한곳에 모아 보는 아카이빙 앱입니다. [Digginn](https://github.com/Digginn) 팀에서 프로덕트 디자인을 맡고 있으며 iOS 앱 출시를 준비 중입니다.
팀 결정 사항을 기능명세서와 피그마 화면에 반영하는 반복 작업은 AI 에이전트가 팀 규칙대로 처리하도록 설계했습니다. [AI 협업 워크플로우 사례 보기](https://leeruji.github.io/work/diggin-ai-workflow/)

**[시사(shisa-agent) UI 개선](https://leeruji.github.io/posts/2026/10/15/shisa-chat-readability/) — 오픈소스 앱 수정 실험**
오픈소스 데스크톱 AI 비서 앱 [cheo0y/shisa-agent](https://github.com/cheo0y/shisa-agent)를 매일 쓰면서 불편했던 화면을 고친 개인 수정판입니다. 원작은 MIT 라이선스로 공개되어 있고 아래 표는 수정판에서 바꾼 부분입니다.

| 바꾼 것 | 내용 |
|---|---|

| 코드 복사 버튼 | 코드 블록마다 「복사」 버튼 |
